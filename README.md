# 👻 Haunted House 3D Scene – Built with Three.js

Welcome to the **creepiest repo on GitHub** 😈  
This is a **3D Haunted House project** built entirely using **Three.js** from scratch.  
No templates. No shortcuts. Just code, chaos, and creepy vibes.

---

## 🔮 Features

- 🏚️ **Textured Haunted House** – with spooky vibes
- 🌳 **Procedural Bushes** – because every haunted house needs some haunted greenery
- ⚰️ **Randomly Placed Graves** – RIP to your bugs
- 🌫️ **Foggy Environment** – for that eerie cinematic effect
- 💡 **Dynamic Lighting** – ambient + directional lights for the perfect spook
